# AGENTS.md — La Fab'ric 1996

## Mission

Tu participes au développement du nouveau site web officiel de **La Fab'ric 1996**, une entreprise québécoise spécialisée depuis près de 30 ans dans :

* Resurfaçage d'armoires de cuisine
* Rénovation de cuisines
* Salle de bain
* Mobilier intégré
* Ébénisterie sur mesure

Tous les développements doivent respecter ce document.

---

## Objectif

Créer le site de référence au Québec dans notre domaine.

Le site doit inspirer confiance, mettre en valeur la qualité du travail et générer des demandes de soumission.

---

## Technologies

* Next.js
* TypeScript
* Tailwind CSS

Toujours privilégier :

* composants réutilisables
* code propre
* performance
* accessibilité
* SEO

---

## Langues

Le site est entièrement bilingue.

Français par défaut.

Anglais disponible via un sélecteur FR | EN.

Toutes les nouvelles fonctionnalités doivent être compatibles avec les deux langues.

---

## Style

Le style recherché est :

* haut de gamme
* moderne
* lumineux
* minimaliste
* intemporel

Le mode clair est la référence.

---

## Couleurs

Palette principale :

* Blanc
* Noir
* Bois naturel
* Gris très pâle

Éviter les couleurs agressives.

---

## Contenu

Ne jamais inventer :

* témoignages
* réalisations
* statistiques
* prix
* coordonnées

Utiliser du contenu temporaire lorsqu'une information est inconnue.

---

## Architecture

Le code doit être simple.

Créer des composants réutilisables.

Éviter les duplications.

Préparer le projet pour plusieurs centaines de réalisations.

---

## Galerie

Le site devra éventuellement gérer :

* cuisines
* salles de bain
* mobilier intégré
* avant / après

Chaque réalisation pourra avoir sa propre page.

---

## Performance

Les images devront être optimisées.

Le site doit obtenir d'excellents résultats sur Google PageSpeed.

---

## Philosophie

Chaque décision doit privilégier :

1. L'expérience utilisateur
2. La qualité visuelle
3. La rapidité
4. La simplicité de maintenance
5. Les demandes de soumission
